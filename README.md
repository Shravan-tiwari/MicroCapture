# Micrographics Capture Software

Professional document digitization workstation software.

## Overview
Built for high-volume digitization with Canon EOS R8 cameras via USB and Canon EDSDK. Focuses on zero-data-loss architecture, rapid operator workflow, and high reliability.

## Key Features
- Canon EOS R8 integration
- Camera settings dashboard (body/lens-supported controls discovered at runtime)
- Live View with document detection
- Zero-data-loss capture & durable queues
- Automated image enhancement & Auto-crop
- Offline OCR (Tesseract)
- Export to searchable PDF, TIFF, JPEG, and PNG
- Planned DMS (Document Management System) integration
